查看 SQLite 資料庫中的內容

輸入以下命令來進入 SQLite 資料庫：
sqlite3 users.db

SELECT * FROM user;

.exit

另一種方式：
安裝 DB Browser for SQLite：
sudo apt install sqlitebrowser

啟動 DB Browser for SQLite：
sqlitebrowser





Flasgger 沒有正確讀取到 API 的描述
Flasgger 需要 API 路由包含對應的 docstring 來生成 Swagger 文件。
需要確保每個 API 路由都有正確格式的 docstring 來描述接口。




docker 啟用時未成功創建資料表，或者資料庫檔案被遺失。
使用資料卷（Volume）來持久化資料庫
在 Docker 中使用資料卷來持久化資料庫，可以保證即使容器被刪除或重啟，資料庫資料仍然保留。
在 Dockerfile 中不改變路徑設置，保持相對路徑配置。
