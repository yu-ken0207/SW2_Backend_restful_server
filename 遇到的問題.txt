查看 SQLite 資料庫中的內容

輸入以下命令來進入 SQLite 資料庫：
sqlite3 users.db

SELECT * FROM user;

.exit

另一種方式：
安裝 DB Browser for SQLite：
sudo apt install sqlitebrowser

啟動 DB Browser for SQLite：
sqlitebrowser
